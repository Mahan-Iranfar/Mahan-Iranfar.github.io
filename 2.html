فناوری فقط چیزی نیست که پشت میز کامپیوتر می‌بینیم.

🔧 سخت‌افزار

Hardware

Hardware = چیزهایی که می‌توانیم ببینیم و لمس کنیم.

CPU RAM Hard Drive / SSD Monitor Keyboard Mouse GPU Smartphone

❓ آیا بدون Hardware می‌توانیم از Software استفاده کنیم؟

→ در نهایت نرم‌افزار برای اجرا به سخت‌افزار نیاز دارد.

💿 نرم‌افزار

Software

Software = برنامه‌ها و دستوراتی که به کامپیوتر می‌گویند چه کاری انجام دهد.

🌐 Chrome 🎨 Photoshop 🎮 Games 💬 WhatsApp 🎵 Spotify 📱 Instagram

❓ Chrome را می‌توانیم لمس کنیم؟

❌ نه. اما می‌توانیم آن را اجرا کنیم و با آن کار کنیم.

Hardware را لمس می‌کنیم؛
Software را اجرا می‌کنیم.

🎨 سمت کاربر

Frontend

چیزهایی که کاربر در یک وب‌سایت می‌بیند و با آن‌ها تعامل می‌کند.

صفحه سایت Button Menu Image Form Animation

🛒 وقتی وارد یک فروشگاه اینترنتی می‌شوی:

👀 چیزی که می‌بینی = Frontend

HTML CSS JavaScript
⚙️ پشت صحنه
